# Taskline To-Do List

A small browser-based To-Do List Management System created for Assignment -1.

## Features

- Add a task
- Mark a task as completed
- Filter all, active, and completed tasks
- Delete tasks
- Persist tasks in browser local storage
- Display completion progress

## Run locally

Open `index.html` in a browser. No build step is required.

## Assignment stories

1. As a user, I want to add a new task to my To-Do List so that I can keep track of my work.
2. As a user, I want to mark a task as completed so that I can identify the tasks I have finished.
